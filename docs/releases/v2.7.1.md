# v2.7.1

## 发布与更新

- 发布流程通过 GitHub Actions 自动生成并上传源码 Release ZIP、离线安装 ZIP 和 `SHA256SUMS` 校验清单。
- 内置更新器从 GitHub Release 获取 ZIP，校验 SHA-256 后再更新，不执行 Git 操作；摘要缺失或不匹配时停止更新。
- 更新前检查包声明的 Tavern API 版本与宿主兼容性，不兼容时停止更新。

## 已知边界

- **凭据存储**：尚未核实宿主是否提供可供插件使用的系统凭据存储接口，也未迁移密钥；当前仍使用插件配置存储。
- **Android**：未进行 Android 真机验证，不能据此宣称 Android Tavern 内嵌环境已获支持。
