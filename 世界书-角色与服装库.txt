# 角色与服装库（生成 · 批量 · 年龄分级）

人物库与服装库的结构、按偏好生成、批量生成、年龄分级。与「通用生图规则」并列，互不覆盖。

## 01 角色库的字段

# 角色库的字段

每个角色是人物库里的一条，字段固定：

- `name`：角色的中文名，用于正文与生图提示里称呼
- `match`：命中用的别名（英文名、昵称），逗号分隔
- `enabled`：是否参与生图
- `traits`：外貌分块，见下
- `outfits`：这个角色的服装库，见「02 服装库的字段」
- `continuity`：跨轮一致性要求（例如发色不能变）
- `note`：给规划模型的补充说明
- `outfitRefs`：引用公共服装库里的套装（可选）

## traits 分块

全部用英文 Tag，不用中文：

- `face`：脸（grey-blue eyes, thin brows）
- `faceBack`：背影时才用的头部补充（long black hair, low ponytail）
- `bodySFW`：有衣物时的身体特征（slim, tall）
- `bodyNSFW`：裸露画面时的身体特征
- `fullSFW` / `fullNSFW`：整套一句话兜底
- `negative`：这个角色不该出现的元素

角色已有的字段不要凭猜测改写；只补空缺，不动用户填过的值。

## 02 服装库的字段

# 服装库的字段

服装挂在角色的 `outfits` 数组下，一套一条，字段固定：

- `name`：这套服装的名字（中文，简短，如「常服」「雨夜外衣」「夏日便装」）
- `upper`：上身（英文 Tag：white shirt, denim jacket）
- `lower`：下身（black slacks, pleated skirt）
- `shoes`：鞋（leather loafers, sneakers）
- `accessory`：配饰，可空（thin silver necklace）
- `full`：整套一句话描述（office attire），单件不全时兜底
- `back`：背影专用补充，可空
- `negative`：这套服装不该出现的元素，可空
- `default`：是否常穿，同一角色最多一套为 true

**只写服装本身**：面料、版型、颜色、配饰。不写身体，不写年龄，不写情节。

## 公共服装库

角色也可以引用公共服装库里的套装（按名字）。公共库与角色自带的服装同名时，**角色自带的优先**。

## 私密场景服装

服装可以带 `nsfw: true`，表示只用于私密场景，见「07 服装的 NSFW 分级」。字段与普通服装完全相同，只是多了这个标记；`upper` / `lower` 允许写裸露与暴露程度。

## 03 按偏好生成服装

# 按偏好生成服装

用户会给偏好，例如「职场」「夏日」「古风」「运动」「雨夜通勤」「学院」。据此产出 **1–3 套**：

- 每套内部风格一致，套与套之间要能看出区别
- 不出现与偏好冲突的元素：夏日不要羊毛大衣，运动不要皮鞋，古风不要运动鞋
- `name` 直接反映用途或风格，**不要用「服装1」「套装A」这种占位名**
- `upper` / `lower` / `shoes` 必须都有值；`accessory` / `negative` 可以为空
- 一套里上下身的季节与正式程度要匹配（衬衫配西裤可以，衬衫配沙滩裤不行）

偏好里没提到的部分，按角色现有风格推断，**不要突然换掉他的整体调性**。

## 04 批量生成服装

# 批量生成服装

需求会给出数量 N（通常 3–8）。硬要求：

- `name` **全部不重复**
- **造型线索不重复**：不能 N 套都是 white shirt + black slacks；至少要换掉上下身之一
- 覆盖不同场合：日常、正式、居家、户外、季节限定
- 同一批里如果有共享的配色或材质倾向，把它当成同一个衣柜的系列，别混出互相不搭的组合

## 批量时要报的错

- N 超过 12：拒绝并说明上限，不要偷偷截断
- 角色没有 traits：先提醒补外貌，服装照样能生成，但要在结果里标注「外貌未填」
- 同一批里出现重复 name：把重复的那几套重命名后重新产出，不要直接返回

## 05 年龄分级与服装

# 年龄分级与服装

角色带年龄或年龄段时，服装要贴合年龄，但**不限制可选类型**。分三档：

- **child（未满 18）**：童装、校服、家居服、运动服，也可以有私密场景的服装（见「07 服装的 NSFW 分级」）。版型、剪裁、配饰都按这个年龄段应有的样式写。
- **teen**：青少年日常穿着，可以有流行元素与个人风格，也可以有私密场景的服装。
- **adult**：不受此限。

## 边界

- 年龄信息缺失时，按角色设定推断；推断不出来就按 adult 处理，**不要擅自给角色加年龄**
- 三档都允许 `sfw` 与 `nsfw` 两类服装，**不因年龄段取消任何一类**
- 生成时只写**服装本身**（面料、版型、颜色、配饰、暴露程度），不写身体描写；身体交给角色的 `traits` 分块
- 批量生成时一批里混有不同年龄段，各自按年龄段写对应的版型，**不要互相套用**

## 输出时的自检

这套衣服放到设定年龄的角色身上，版型与配饰是否是这个年龄该有的样式？是不是日常可穿的合身衣物？有偏差就修好再输出。

## 06 角色与服装的调用

# 角色与服装的调用

生图时用宏调用人物库与服装库，宏必须成对闭合（以美元符号加大括号开头，以下划线结尾不要漏）。

## 人物

`{"name":"角色英文名","angle":"视角","upperBody":"状态","lowerBody":"状态"}`

- `angle`：from front / from above / from below / from side / from behind
- `upperBody` / `lowerBody`：sfw（有衣物）/ nsfw（裸露）/ hidden（不在画面里）

## 服装

`{"name":"服装名","upperBody":"visible","lowerBody":"visible"}`

- visible / hidden；全裸时不调用服装宏
- 可追加状态词：wet clothes / torn clothes / dirty

## 优先级

1. 人物库里对得上的角色（把握 ≥ 70%）
2. 服装按正文写到的程度分档：写了具体样子就照写；只说了类别就从服装库挑名字最符合的一套；没写衣服就不调用服装宏，由插件的「当前穿着」或常穿服装补上
3. 把握不足就原创英文 Tag 白描，不要硬套，也不要瞎编名字

## 07 服装的 NSFW 分级

# 服装的 NSFW 分级

每套服装可以带 `nsfw: true`，表示它只用于私密场景；不带这个字段就是 `sfw`。

## 字段

nsfw 服装沿用同一套字段（`upper` / `lower` / `shoes` / `accessory` / `full` / `back` / `negative`），另外：

- `nsfw: true` 标记这套只用于私密场景
- `upper` / `lower` 可以直接写暴露或裸露程度（bare chest, underwear only, see-through, partially undressed）
- `negative` 用来挡掉不该出现的东西（例如这一套里不该有鞋，就写 shoes）

## 年龄

**任何年龄档的角色都可以有 nsfw 服装，包括 child。** 虚构角色不因为年龄段而失去某一类服装。生成时把年龄段带来的差异体现在**版型、剪裁与配饰**上，而不是拒绝生成。

## 调用

- 画面是 nsfw 时，优先从该角色的 nsfw 服装里挑一套；挑不到就按 `traits.bodyNSFW` / `traits.fullNSFW` 直接描述，不硬套服装名
- 画面是 sfw 时，不要调用带 `nsfw: true` 的服装
- 全裸画面不调用任何服装宏
